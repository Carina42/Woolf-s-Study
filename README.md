# 植物探案所 · Woolf’s Study

一个可在电脑和手机浏览器运行的像素风互动书房场景。手机横屏浏览效果最佳。

## 文件

- `index.html`：游戏页面与互动逻辑
- `rain-window-source.mp3`：雨声
- `chopin-nocturne-source.mp3`：古典乐

页面和两个音频文件应放在仓库根目录。音频素材此前从 Pixabay 获取；请保留原下载记录。许可说明：[Pixabay Content License](https://pixabay.com/service/license-summary/)。雨声素材：[Nature Indoor Hard Rain Sound](https://pixabay.com/sound-effects/nature-indoor-hard-rain-sound-190883/)。

## 本地预览

在此目录启动静态文件服务器，访问 `http://localhost:8000`。同一 Wi‑Fi 下可用手机打开电脑的局域网地址。

## GitHub Pages

文件放在仓库根目录后，进入 **Settings → Pages**，选择从 `main` 分支的根目录发布。手机浏览器打开 GitHub Pages 链接即可。
